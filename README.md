# SQL-Data-Analytics-Project
Practical SQL scripts for analytics — from database exploration to segmentation, trends, and reporting. Built for analysts, by an analyst.
---

## 🔵 Exploratory Data Analysis (EDA)

| # | Script | Description |
|---|--------|-------------|
| 1 | `01_database_exploration.sql` | Inspect schemas, tables, and columns |
| 2 | `02_dimensions_exploration.sql` | Explore dimension tables and categories |
| 3 | `03_date_exploration.sql` | Analyze date ranges and time boundaries |
| 4 | `04_measures_exploration.sql` | Big numbers — totals, averages, counts |
| 5 | `05_magnitude.sql` | Compare sizes and volumes across groups |
| 6 | `06_ranking.sql` | Top-N and Bottom-N analysis |

---

## 🟢 Advanced Analytics

| # | Script | Description |
|---|--------|-------------|
| 7 | `07_change_over_time.sql` | Trends and period-over-period comparisons |
| 8 | `08_cumulative_analysis.sql` | Running totals and cumulative growth |
| 9 | `09_performance_analysis.sql` | KPIs and performance benchmarking |
| 10 | `10_part_to_whole.sql` | Proportional and contribution analysis |
| 11 | `11_data_segmentation.sql` | Customer and product segmentation |
| 12 | `12_reporting.sql` | Final report-ready queries for dashboards |

## 🛠️ Tech Stack

- **Database:** Microsoft SQL Server
- **Language:** T-SQL (Transact-SQL)
- **Tool:** SQL Server Management Studio (SSMS)
